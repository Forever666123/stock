# SOXL × FOMC 历史条件复核

把上一轮 chat 里靠工具调用堆出来的结论，固化成可复现的脚本。数据、FOMC 日历、每条条件的定义都在代码里，改一个阈值就能重跑。

## 复现

```bash
pip install -r requirements.txt
bash data/fetch.sh            # 可选：更新到最新交易日
python3 -m analysis.run       # 生成 results/report.md
```

## 结构

| 路径 | 内容 |
|---|---|
| `data/SOXL_OHLC.csv` | SOXL 日线 2010-03-11 起，Yahoo 除权口径 |
| `data/phase5_close_qqq.parquet` | QQQ 收盘 2018-01-02 → 2026-05-22 |
| `data/holdings_prices_1y.json` | QQQ / SOXX / SPY 最近 252 天收盘 |
| `analysis/data.py` | 读数、拼接 QQQ 两个源（收益率不跨接缝）、算前收/跳空/最低/前瞻收益 |
| `analysis/fomc.py` | 2015–2025 决议日与动作（加息 20 / 按兵 58 / 降息 9 + 2 次紧急），2026 日期未验证不入统计 |
| `analysis/run.py` | 九条条件 + 已推翻说法的回归复核 + 当前位置，输出 `results/report.md` |
| `results/report.md` | 最近一次运行结果 |

## 复核结论（对照上一轮摘要）

完整数字见 `results/report.md`。这里只列**复核后哪些变了**。

**原样复现的（数字对得上）**

- 条件 1 杠杆穿仓：跳空 ≤ −10% 且当日到 −22% 的 11 个样本，成交后当日再跌中位 −10.1%，10x 6/11、5x 2/11、3x 0/11 穿仓。拉到 20 日，3x 也有 6/11 穿仓。
- 条件 2 加仓算术：10x 两笔强平 83.7，5x 一笔 77.0。
- 条件 4 会前大跌不改加息：5/5 全加，2022-06-15 会前 QQQ −7.85% 换来 75bp。
- 条件 5 D-1 均值：+0.456% vs +0.330%（n=87 vs 2853），加息会 D-1 上涨 14/20。
- 条件 8 QQQ 否决：坏日子 QQQ 0/17 收涨，好日子 QQQ 中位 −1.37%。
- 条件 9 深挂单：−15.5% 触发 75% 但 EV −2.7%，−22% 转正，−24.9% 次日 8/10、当日最深 −19.0%。

**复核后要打折的**

- 条件 5 D-1 偏强：均值差在置换检验下 p = 0.85，上涨率 55% vs 54%。加息会 14/20 在基准下 p = 0.11。SOXL 自己的数据撑不起这条，只能靠外部文献。有无发布会分组也看不出差别。
- 条件 6 板块独跌：上涨率和中位数上"3 日偏弱"成立（45% vs 50%，中位 −2.4% vs +0.6%），但均值上不成立（+0.9% vs +1.9%，p = 0.65），10 日更是反过来。独跌组 23/79 个样本来自 2026 年，这一年独跌后 10 日均值 +6.4%。剔除 2026 后 3 日 41% vs 51%。方向可信，幅度不可信。
- 条件 7 没有超跌反弹：跌幅越大次日上涨率单调上升（−5% 55% → −15% 65%），p 在 0.05–0.1 之间。说"与基准无差"略强，说"没有可交易边际"没问题。
- 条件 3 挂单：全历史 −15.5% 触发 83 次而不是 69，只成交第一单胜率 56%（原 64%），两单都成交 35%（原 32%）。方向一致。

**新增的**

- 条件 9 补了 5 日内最糟：每一档都在 −50% 上下（2020-03、2025-04）。深挂单减少的是当日的痛，不是持仓风险。
- "反弹确认再买"在跳空 ≤ −10% 子集里相关性 −0.44（n=40），比原来的 −0.295 更强；在收跌 ≤ −8% 全集里只有 −0.04。这条是"跳空日"专属。
- "顶部第一砸好抄"相关性 −0.21（原 −0.44），同号但更弱。

**没做的**

- CPI/PPI → FOMC 周一 13/15 那条需要 BLS 发布日历，本环境访问不到 bls.gov。

## 当前位置（数据截至 2026-09-11）

- 9/10 SOXL −8.03%、QQQ −1.06%，满足"板块独跌"定义；9/11 反弹 +5.2%，反弹本身不是进场理由（跳空日子集里越弹越差）。
- 距 7/29 前低 91.5 为 −24.9%，距 60 日高 300.77 为 −59.5%。
- 9/16 FOMC 决议日，9/15 为 D-1。条件 5 和条件 6 方向相反，且条件 5 在 SOXL 数据上不显著。

## 方法论规矩

1. n<50 只能找反例，不能下结论。
2. 先有机制再看数字。
3. 指标必须盘中可得。"收盘距最低收回"只用于事后分类。
4. 一次只用一个进场条件。
